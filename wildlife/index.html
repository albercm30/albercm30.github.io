FIELD NOTES

The map turns scattered observations into a record of where curiosity has taken me.

This is deliberately more than a map widget. It is a small data pipeline: iNaturalist observations are fetched with Python, normalized into a compact JSON dataset, published to GitHub Pages and then rendered here with Leaflet. The same dataset can later power species pages, country pages, travel logs and photography stories across the site.
