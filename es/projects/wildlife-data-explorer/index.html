PERSONAL · VISUALIZACIÓN DE DATOS

Wildlife Data Explorer

Una plataforma de datos personal que conecta avistamientos de fauna, lugares, inmersiones, viajes y fotografía, y que es el motor real detrás de las páginas de Fauna, Buceo y Viajes de esta web.

El problema

Años de viajes producen siempre el mismo problema: fotos en un sitio, coordenadas GPS en ninguno, nombres de especies medio recordados y ninguna forma de responder a una pregunta sencilla como «¿qué he visto realmente y dónde?» sin repasar el carrete de la cámara. Quería un único conjunto de datos estructurado que pudiera responder a eso y que se dibujara solo como un mapa, no solo como una hoja de cálculo.

Decisiones técnicas

Cada avistamiento, inmersión y viaje vive como un registro en un conjunto de datos JSON (especie, lugar, coordenadas, fecha y enlaces al país y al punto de buceo al que pertenece) y no como prosa, de modo que los mismos datos pueden alimentar un mapa, una lista filtrable y futuras estadísticas sin volver a introducir nada. Python se encarga de la limpieza y la validación de esos datos antes de publicarlos.

Los mapas funcionan con Leaflet y teselas de OpenStreetMap en lugar de un widget de mapa de terceros incrustado, lo que mantiene el estilo totalmente en la paleta de colores de la web y deja que cada marcador lleve datos propios: un div hecho a mano como icono, con tamaño según el número de avistamientos y con un popup construido a partir del mismo registro JSON. Como todo es JSON estático y no una base de datos en vivo, toda la web se publica como simples archivos en GitHub Pages, sin backend que mantener.

Resultado

El conjunto de datos respalda ahora tres páginas activas (Fauna, Buceo y el archivo de países dentro de Viajes), con más de 200 registros de especies y 19 inmersiones registradas, cada una dibujada en su propio mapa interactivo con marcadores y popups personalizados.

Próximos pasos

El siguiente paso más claro es enlazar los datos entre sí: al hacer clic en un país del archivo deberían aparecer las inmersiones y los avistamientos registrados allí, ya que los datos subyacentes tienen estructura compartida suficiente (coordenadas, país, fecha) para unir los tres conjuntos; simplemente todavía no está conectado en la interfaz.
